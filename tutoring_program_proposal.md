So based on the research I did on the tutoring program, one of the biggest issues that kept appearing was communication and organization. Right now, most of the tutoring process is done manually — Ani and I have had to email tutors and tutees individually, follow up ourselves, coordinate schedules, etc., which becomes really difficult as the program grows.

The goal of the website would basically be to centralize and automate the entire tutoring process so it's more efficient, accessible, and sustainable for future Academy leadership.

Some things I was thinking the website could include:

- A tutor request form where students can select:
  - subject
  - class level (honors/AP/etc.)
  - availability
  - what they need help with

- A tutor side where tutors can:
  - sign up for subjects they can tutor
  - enter their availability
  - manage tutoring requests

- Automatic matching/scheduling between tutors and tutees based on subject + availability

- Automatic emails or notifications:
  - confirming matches
  - reminding students about sessions
  - following up if nobody responds

- A system that keeps track of:
  - tutoring requests
  - completed sessions
  - most requested subjects
  - tutor participation/activity

- Have students enter their current grade/percentage in the class when submitting a tutoring request so improvement can be tracked over time

- Include an automatic post-tutoring feedback form where students can report:
  - whether tutoring helped
  - updated grades
  - comfort level during sessions
  - overall satisfaction

- Track how many tutoring sessions each student attends so leadership can analyze whether more consistent participation leads to greater improvement

- Allow tutors to briefly log what topics were covered during sessions to identify the most commonly requested areas of support

- Generate long-term program data automatically so future Academy leadership can evaluate trends and improve the system without manually organizing spreadsheets and surveys every year

One thing I really want is for it to reduce the amount of manual coordination leadership has to do, because right now the process depends heavily on people individually keeping track of emails and spreadsheets. Ideally, the website would make the system more centralized and easier to maintain long-term.

I also think it would be cool if the interface looked clean/simple and was easy for students to use quickly without needing a whole account creation process or anything super complicated
